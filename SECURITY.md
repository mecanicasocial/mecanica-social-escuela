# Seguridad

No incorporar al repositorio:

- contraseñas;
- tokens;
- claves API;
- datos personales innecesarios;
- evaluaciones individuales;
- documentos reservados;
- información financiera sensible.

Si una herramienta de IA requiere una clave API, esta debe mantenerse como secreto del entorno y nunca escribirse en el código o documentación pública.
