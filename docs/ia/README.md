# Modelo de IA de apoyo a la Escuela

Este documento describe de forma resumida el modelo de IA de apoyo, su propósito, y el marco de uso responsable.

## Propósito
- Soporte en generación de materiales, generación de preguntas, evaluación formativa automatizada y asistencia en tutorías.

## Alcance
- Asistencia a docentes y estudiantes; no reemplaza decisiones pedagógicas humanas.

## Datos y privacidad
- Evitar usar datos personales sensibles.
- Anonimizar datasets cuando se usen para entrenamiento o evaluación.

## Consideraciones éticas
- Señalar sesgos conocidos y limitar uso en decisiones críticas.
- Supervisión humana obligatoria para recomendaciones que afecten evaluación o acceso.

## Modelos y herramientas sugeridas
- Modelos de lenguaje para generación de texto (configuración recomendada)
- Pipelines para evaluación automatizada (rubricas + modelos)
