# Indicadores

## Cobertura

- Postulantes.
- Participantes seleccionados.
- Asistencia.
- Egresados.

## Aprendizaje

- Evaluación inicial.
- Evaluación final.
- Evidencias de aprendizaje.
- Satisfacción.

## Proyectos

- Proyectos iniciados.
- Proyectos terminados.
- Proyectos implementados.
- Beneficiarios.

## Indicador estratégico

**Índice de Transformación Comunitaria = proyectos implementados / proyectos desarrollados × 100**
