# Metodología de la Escuela

La metodología sigue la ruta propuesta: Idea → Issue → Planificación → Desarrollo → Revisión → Pull Request → Aprobación → Publicación → Evaluación.

Principios pedagógicos:
- Aprendizaje activo
- Evaluación formativa
- Inclusión y accesibilidad
- Uso reflexivo y responsable de IA

Flujos clave:
- Cada idea debe documentarse con la plantilla [IDEA].
- La planificación concreta se documenta con [PLANIFICACIÓN] y define entregables y criterios de aceptación.
- El desarrollo tiene checklist técnico y de contenido antes de solicitar revisión.
- Las revisiones comprenden revisión pedagógica, técnica y de IA cuando aplique.
