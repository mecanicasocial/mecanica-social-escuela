# Entregable

## Informe de Análisis Institucional Territorial

### Extensión

Entre 1.000 y 1.500 palabras.

### Estructura

1. Introducción.
2. Descripción del problema.
3. Identificación de instituciones.
4. Competencias y atribuciones.
5. Relación entre instituciones.
6. Participación ciudadana.
7. Conclusiones.

### Formato

- Markdown o PDF.
- Tablas permitidas.
- Incorporar referencias utilizadas.

### Criterios de calidad

- Claridad conceptual.
- Correcta identificación institucional.
- Relación entre problema e instituciones.
- Fundamentación.
