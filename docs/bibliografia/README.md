# Bibliografía base

Esta carpeta debe mantener una **bibliografía curada y versionada**, organizada por módulo.

## Criterios de selección

1. Relevancia académica.
2. Autoridad de la fuente.
3. Actualidad cuando el tema lo requiera.
4. Accesibilidad.
5. Diversidad de perspectivas.
6. Licencia o posibilidad legítima de acceso.
7. Identificación clara de autor, año y enlace.

## Categorías

- Democracia y ciudadanía.
- Instituciones y Estado.
- Políticas públicas.
- Participación ciudadana.
- Liderazgo.
- Comunicación.
- Pensamiento crítico.
- Ética pública.
- Innovación social.
- Tecnología e IA.

## Fuentes institucionales sugeridas

- Biblioteca del Congreso Nacional de Chile.
- Gobierno de Chile.
- Contraloría General de la República.
- CEPAL.
- UNESCO.
- OCDE.
- Naciones Unidas.
- Banco Mundial.
- GitHub Education / GitHub Docs.

La bibliografía definitiva debe ser aprobada por la coordinación académica antes de marcarla como `APROBADA`.


## 📊 REPOSITORIOS DE DATOS ABIERTOS Y FUENTES CUANTITATIVAS
Para el desarrollo del **Punto 1 (Diagnóstico)** utilizando datos objetivos y medibles del territorio chileno, se autoriza y recomienda el uso de las siguientes plataformas oficiales:

*   **[Portal de Datos Abiertos del Estado](https://datos.gob.cl/):** Repositorio centralizado con más de 3,000 conjuntos de datos de ministerios y municipalidades en formatos CSV y JSON.
*   **[Datos Abiertos de la Biblioteca del Congreso Nacional (BCN)](https://datos.bcn.cl/):** Indicadores sociales, económicos, mapas distritales y datos estadísticos de comunas de Chile.
*   **[Base de Datos de Ley Chile (BCN)](https://www.bcn.cl/leychile):** Acceso al texto completo de la **Ley N° 20.285** (Transparencia Pública) y la **Ley N° 20.500** (Participación Ciudadana).
