# Bibliografía base

Esta carpeta debe mantener una **bibliografía curada y versionada**, organizada por módulo.

## Criterios de selección

1. Relevancia académica.
2. Autoridad de la fuente.
3. Actualidad cuando el tema lo requiera.
4. Accesibilidad.
5. Diversidad de perspectivas.
6. Licencia o posibilidad legítima de acceso.
7. Identificación clara de autor, año y enlace.

## Categorías

- Democracia y ciudadanía.
- Instituciones y Estado.
- Políticas públicas.
- Participación ciudadana.
- Liderazgo.
- Comunicación.
- Pensamiento crítico.
- Ética pública.
- Innovación social.
- Tecnología e IA.

## Fuentes institucionales sugeridas

- Biblioteca del Congreso Nacional de Chile.
- Gobierno de Chile.
- Contraloría General de la República.
- CEPAL.
- UNESCO.
- OCDE.
- Naciones Unidas.
- Banco Mundial.
- GitHub Education / GitHub Docs.

La bibliografía definitiva debe ser aprobada por la coordinación académica antes de marcarla como `APROBADA`.
