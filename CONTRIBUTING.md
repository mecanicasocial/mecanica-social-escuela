# Contribuir

1. Crear una rama.
2. Explicar el objetivo del cambio.
3. Trabajar con fuentes verificables.
4. No incorporar datos personales ni material sin autorización.
5. Abrir Pull Request.
6. Solicitar revisión.
7. Publicar solo después de aprobación.

## Convenciones

- Documentos: Markdown cuando sea posible.
- Nombres de archivos: minúsculas y guiones.
- Versiones: `v01`, `v02`, etc.
- Cada recurso académico debe indicar sus fuentes.
