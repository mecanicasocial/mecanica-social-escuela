# Flujo de entregables

Cada curso tendrá:

1. Programa.
2. Guía docente.
3. Presentación o material de apoyo.
4. Lecturas obligatorias.
5. Lecturas complementarias.
6. Actividad práctica.
7. Plantilla de trabajo.
8. Rúbrica.
9. Entregable.
10. Retroalimentación.
11. Versión final.
12. Evidencia de aprendizaje.

## Convención de nombres

`CURSO##_TIPO_NOMBRE_v01.ext`

Ejemplo:

`CURSO05_GUIA_ARBOL_PROBLEMA_v01.docx`

## Estados

- `BORRADOR`
- `EN_REVISION`
- `APROBADO`
- `PUBLICADO`
- `ARCHIVADO`
