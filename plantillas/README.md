# 📁 REPOSITORIO DE RECURSOS Y PLANTILLAS
## ESCUELA DE FORMACIÓN POLÍTICA MARCELO ORELLANA LAGOS

Este directorio constituye el núcleo metodológico de la **ONG Mecánica Social**. Reúne las estructuras estandarizadas necesarias para la gestión pedagógica, el diseño de proyectos comunitarios bajo el enfoque de Marco Lógico y la evaluación docente.

---

## 🗺️ Catálogo de Componentes Académicos

### 1. Área del Estudiante
*   **[Plantilla de Entregable Académico](entregable.md):** Formato oficial obligatorio para informes de módulos. Incluye secciones de Diagnóstico Territorial de Chile, Propuesta Estratégica y Matriz de Impacto con Intake ID y Declaración Ética de IA.

### 2. Área Docente y de Planificación
*   **[Guía Docente Institucional](guia_docente.md):** Estructura base para directrices de profesores y criterios homologados de evaluación.
*   **[Ficha de Actividad](ficha_actividad.md):** Formato para el diseño de talleres prácticos y dinámicas territoriales participativas.
*   **[Plantilla de Guía de Curso](plantilla-guia-curso.md):** Matriz para la construcción de sílabos y objetivos modulares.

### 3. Área de Gestión y Biblioteca
*   **[Plantilla de Ficha Bibliográfica](plantilla-ficha-bibliografica.md):** Estructura de indexación para el repositorio `ms-biblioteca` y fuentes normativas.
*   **[Plantilla de Issue de Proyecto](plantilla-issue-proyecto.md):** Formato para el levantamiento técnico de nuevas iniciativas en GitHub.

---

## 🛠️ Reglas de Uso y Control de Versiones
1. **Inmutabilidad:** Ninguna plantilla debe modificarse localmente en la rama `main`. Cualquier cambio estructural debe proponerse mediante un Pull Request.
2. **Sincronización:** Toda modificación en estos archivos debe notificarse al equipo de desarrollo de IA para mantener actualizados los validadores de la Consola Virtual.
