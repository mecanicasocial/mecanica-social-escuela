# Datos de la carpeta data/

**Todos los datos de esta carpeta son FICTICIOS.** Se crearon solo para probar el motor de admisión y la consola de la Escuela.

- Las personas, comunas, organizaciones y puntajes de `samples/`, `output/` y `logs/` son inventados.
- Cualquier parecido con personas u organizaciones reales es coincidencia.

## Regla obligatoria

**No subir a este repositorio datos de postulantes reales**: nombres, RUT, contactos, organizaciones, evaluaciones ni resultados de admisión. Los datos reales se guardan en el repositorio institucional privado (ver `SECURITY.md`).

## Contenido

- `samples/`: fichas de postulantes de ejemplo.
- `output/`: resultados de prueba generados por los scripts de evaluación.
- `logs/`: ejemplo del registro de auditoría (ver `logs/README.md`).
