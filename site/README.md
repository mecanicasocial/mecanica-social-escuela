# Instrucciones para GitHub Pages

El sitio público utiliza la carpeta `site/`. Para desplegar GitHub Pages:

1. Configurar en Settings → Pages la rama `main` y la carpeta `/site`.
2. Añadir contenido en `site/` (index.md, etc.).
3. Construir con tu generador preferido (Jekyll, MkDocs, etc.).

Este repo incluye un `site/README.md` con instrucciones básicas.
